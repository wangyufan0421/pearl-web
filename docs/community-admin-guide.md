# 社区讨论后台操作

进入 `/admin/community-discussions`，用服务器配置的统一管理员密钥验证。英文入口为 `/en/admin/community-discussions`。后台内页面跳转保留验证状态，退出或整页刷新后重新验证。

## 首页

每张卡片对应一组主题帖与辩论/引推。点击卡片标题进入管理页。顶部加号进入新建页。公开/已隐藏筛选切换显示范围。

- **隐藏讨论**：确认后从公开列表及详情隐藏。原文、回应、头像、账号和译文保留。在已隐藏列表点击恢复公开即可恢复。
- **彻底删除**：确认框显示完整标题，并要求输入该讨论的地址标识。确认后数据库会在同一个操作中删除主题及所有关联来源和译文，无法恢复。

## 新建与管理

新建页左侧填写主题帖链接及可选标题、简介、地址标识，右侧可填写辩论/引推链接，一行一条。提交先保存主题帖，再添加回应；如果回应失败，进入已创建主题的管理页检查结果和重试，避免重复创建主题。

管理页左侧展示已归档主题，可切换译文或原文并刷新来源；右侧添加回应及查看已有回应。重复来源不会再次添加，抓取失败的来源可重试。

隐藏使用已有 `draft` 状态；此次升级不需要数据库迁移。后台新增读取和管理接口均验证管理员密钥。云端部署新版前端和服务端后重启网站及翻译服务即可；单独上传前端不能启用新的后台接口。

自动翻译只扫描公开讨论。隐藏时已经进行的翻译请求可能完成并保存；隐藏期间不再开始新的扫描任务。恢复后待完成的翻译继续执行。彻底删除后，在途翻译不会重新插入已删除的数据。
