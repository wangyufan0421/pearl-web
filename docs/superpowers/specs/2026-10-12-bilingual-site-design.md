# Pearl 中英文网站设计

已确认：共用 React 页面与数据；中文保留现有 URL，英文使用 `/en` 前缀；全站右上角 EN / ZH 切换，保留对应页面、查询参数、锚点及当前图表状态；记住主动选择。显式 URL 决定语言，记忆用于后续访问根入口。网页正文、提示、可访问标签、日期数字、页面标题与描述均随语言切换。英文 PDF 使用原版英文白皮书，中文使用现有译文；社区原帖不翻译，不在此功能中补建尚未接入的社区前端。

文案放入集中英文目录，中文源文案作为稳定查找键。页面通过语言 hook 显式翻译文字，不依赖浏览器翻译或 DOM 替换。共用导航组件提供语言按钮和本地化站内地址；静态资源、API、外链不增加语言前缀。原帖正文将来接入时须明确绕开翻译函数。

语言切换通过 History API 原地更新路径并通知组件，不重新挂载页面，因此图表选择得以保留。返回与前进同步语言和页面。存储不可用时仍正常切换。格式化统一按 zh-CN / en-US 选择。页面标题和描述按路由及语言更新，HTML lang 同步。

验证：所有现有页面的英文正文和提示无中文残留；切换保留页面及图表选择；中文链接保持原路径；英文链接保持前缀；PDF 检查实际语言与对应版本；已有回归测试、类型检查与生产构建通过。
